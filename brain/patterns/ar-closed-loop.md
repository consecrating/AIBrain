# Closed-Loop Action Attribution

- **ID:** AR-004
- **Problem:** Automated recommendations are useless if their real impact is never measured.
- **Use when:** A system proposes and applies changes over time.
- **Source:** GOAAISEO

## Solution

Link each action to its evidence, approval, write-back event, affected entities, and expected leading indicator. Measure later ground-truth outcomes against a baseline and feed the result into future prioritization.
