# Confidence-Gated Action Candidates

- **ID:** AR-003
- **Problem:** AI findings vary in reliability but still need to remain visible.
- **Use when:** Analysis can create autonomous work.
- **Source:** goaaiseo-seo-adapter

## Solution

Persist every finding with evidence and confidence, but mark only candidates above the configured threshold as scheduling-ready. Low-confidence candidates stay in suggestion mode rather than disappearing or executing.
